# Marketing Campaign Analysis

## 📌 Project Overview

This project analyzes customer behavior, marketing campaign engagement, product performance, and customer reviews using SQL Server and Power BI.

## 🎯 Business Objectives

- Analyze customer demographics and locations
- Understand marketing engagement by content type
- Compare campaign performance
- Analyze customer product ratings and reviews
- Identify highly rated products
- Generate actionable business insights

## 📊 Dataset

The project contains five datasets:

- Customers
- Countries
- Customer Reviews
- Engagement Data
- Products

## 🛠️ Tools & Technologies

- SQL Server
- SQL
- Power BI
- DAX
- Data Cleaning
- Data Analysis
- Data Visualization

## 🧹 Data Cleaning & Preparation

- Checked missing values
- Checked duplicate records
- Handled 5 missing View values in engagement data
- Validated relationships between tables
- Performed SQL-based data validation and analysis
